# نافس باجتهاد 🌟 — أكاديمية ألوان

منصة عربية (RTL) لبناء عادة الاجتهاد عند الطلاب: مهام، تقويم، أهداف، اتفاق الهمة، تحديات، نقاط وأوسمة، مؤشر اجتهاد، خطة مذاكرة تلقائية، وتقرير أسبوعي (PDF + واتساب).

الرابط: https://abod1917.github.io/alwan-nafes/

## كيف تعمل
- **البداية:** يختار الزائر «أنا طالب» أو «أنا ولي أمر» أو «تسجيل الدخول».
- **تسجيل الطالب:** الاسم، العمر، الصف، المدرسة، الرمز، والأهداف من خيارات جاهزة (رفع الدرجات، الرياضيات، القراءة، القرآن، الإنجليزية، العلوم، تنظيم الوقت، الاختبارات) مع هدف خاص ووقت مذاكرة يومي.
  - تُبنى له تلقائيًا أهداف، ومهام أسبوعه الأول، والتحديات المناسبة، و«أفكار لك».
  - يحصل على اسم مستخدم ورمز ربط من 6 خانات يعطيه لولي أمره.
- **تسجيل ولي الأمر:** اسمه، صفة القرابة، الجوال (اختياري)، ثم:
  - إما **رمز الربط** إن كان الابن مسجّلًا، فيرتبط به مباشرة،
  - أو بيانات الابن وأهدافه فيُنشأ الابن تحته، ويستطيع لاحقًا إنشاء حساب دخول خاص له.
  - يمكنه ربط أو إضافة أبناء آخرين من لوحته.
- **الإدارة (المشرف):**
  - «المسجلون»: كل الطلاب وأولياء الأمور ببياناتهم وأهدافهم وارتباطاتهم، مع بحث وتصدير CSV وإعادة تعيين الرقم السري وتعطيل الحساب.
  - الأسر، والتحديات، والمحتوى، والأوسمة، والتقارير.

## البنية
- **الواجهة:** موقع ثابت بلا خطوات بناء (`index.html`، `css/`، `js/`)، يُنشر على GitHub Pages عبر `.github/workflows/pages.yml`.
- **البيانات:** Supabase (مشروع `nafes-bjtihad`). الجداول مغلقة أمام المفتاح العام، وكل الوصول عبر دوال RPC تتحقق من رمز الجلسة. التعريف الكامل في `supabase/migrations/0001_nafes.sql`.
  - الطالب يرى ويعدّل بياناته فقط، وولي الأمر يرى أسرته فقط، والإدارة ترى الجميع.
  - الأرقام السرية مشفّرة (bcrypt)، والحساب يُقفل 15 دقيقة بعد 5 محاولات خاطئة.
  - **الحذف ناعم:** المحذوف يُخفى ولا يُمسح، ويمكن استرجاعه من قاعدة البيانات عند الخطأ.
- **الملفات:**

| الملف | المحتوى |
|---|---|
| `js/core.js` | مؤشر الاجتهاد والنقاط والأوسمة وخطة المذاكرة |
| `js/data.js` | خيارات الأهداف والخطة المبدئية |
| `js/sync.js` | المزامنة مع قاعدة البيانات |
| `js/onboard.js` | البداية والتسجيل |
| `js/views.js` | صفحات الطالب وولي الأمر |
| `js/admin.js` | لوحة الإدارة |
| `js/app.js` | التوجيه |
