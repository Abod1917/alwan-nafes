# نافس باجتهاد 🌟 — أكاديمية ألوان

منصة عربية (RTL) لمتابعة اجتهاد الطلاب: مهام، تقويم، أهداف، اتفاق الهمة، تحديات، نقاط وأوسمة، مؤشر اجتهاد، خطة مذاكرة تلقائية، وتقرير أسبوعي (PDF + واتساب). ثلاث واجهات: **الطالب**، **ولي الأمر**، **إدارة الأكاديمية**.

## التشغيل
موقع ثابت بلا خطوات بناء: افتح `index.html` أو شغّل `python3 -m http.server`.
النشر: GitHub Pages عبر `.github/workflows/pages.yml` (Settings → Pages → Source: GitHub Actions).

## حسابات التجربة
| الدور | المستخدم | الرقم السري |
|---|---|---|
| أسرة (عبدالله + نورة) | `NAFES1001` | `4826` |
| الإدارة | `admin` | `0000` (غيّره من التقارير ← تغيير رقم الإدارة) |

## ملاحظات مهمة
- **التخزين حاليًا في متصفح الجهاز (localStorage)**: كل جهاز له بياناته، ولا تتزامن بين ولي الأمر والطالب على جهازين. للإنتاج اربط Supabase باستخدام `supabase/schema.sql` (يشمل RLS).
- الدخول بالـ PIN للتجربة فقط، وليس أمانًا حقيقيًا قبل الربط بقاعدة البيانات.
- مؤشر الاجتهاد (آخر 7 أيام): إنجاز المهام 30 · الالتزام بالمواعيد 15 · وقت المذاكرة 15 · التركيز 10 · السلسلة 15 · الأهداف 15. المستويات: 🌱 <40 · ⭐ 40 · 🔥 65 · 🏆 85.

## البنية
`js/core.js` المحرك · `js/data.js` البيانات التجريبية · `js/views.js` الطالب وولي الأمر · `js/admin.js` الإدارة · `js/app.js` التوجيه والدخول · `assets/` الشعارات (فاتح/داكن).
